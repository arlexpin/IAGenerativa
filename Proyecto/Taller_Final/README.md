# Agente de IA para Automatización de Devoluciones – EcoMarket

## Descripción
Agente de IA que automatiza el proceso de devolución de productos en EcoMarket. Integra un sistema RAG para responder preguntas generales y herramientas para verificar elegibilidad y generar etiquetas de devolución.

## Requisitos
- Python 3.10+
- Ollama con modelo `llama3.1:8b` descargado
- Dependencias: ver `requirements.txt`

## Instalación
```bash
git clone https://github.com/EcoMarket/agent-final
cd agent-final
pip install -r requirements.txt
